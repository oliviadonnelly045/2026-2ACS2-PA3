# 2026-2ACS2-PA3
Design Thinking Final Passion Project

Empathize: A high school junior at the Madeira School who struggles to organize and keep track of the work they need to do and does not know how to plan their schedule to do their work

Research: 
    -> in person interviews with juniors at the Madeira School (both people who struggle with keeping track of their work and people who have found a solution to this problem)
        - Students who have a planner tend to remember what they have to do better
        - Keeping a calendar helps students keep track of their work and schedule
        -> in the process of planning interviews with students
    -> internet research (blogs, social media, news, etc.)
        - find people who struggle with similar problems/high school juniors at other schools

Define: How might we help high school juniors remember and keep track of their work?
        How might we help high school juniors plan their schedules?


Ideate:
    1. Calendar/schedule creator
    2. Planner
    3. Time planner (block out time to do work)
    4. To-Do list
    5. Schedule/planer - write out schedule, block out time to do work, and the work that is due



Prototype: A program that allows the user to add to, remove from, and view their weekly schedule. It allows the user to choose the day they want to add to, the time of the event, and the event name. It then and then saves their changes to a dictionary and then saves that to a .txt file with the full weekly schedule. The user can choose to remove all events from the chosen day. Users are then able to view their schedule by printing the .txt file.


Test & Reflect:
    WWW: I was able to create a working program that allows the user to add and remove events from their weekly schedule. I was able to make it so the user could log their daily schedules in dictionaries that saved the full weekly schedule to a .txt file that could be printed to show their full schedule.

    EBI: I had a hard time figuring out how to get the dictionary to save into the .txt file and print the full schedule without just printing the empty dictionaries. Eventually, I figured it out by changing it so there is not an individual dictionary for each day and learned how to fix this problem in the future.

    IMT: If I had more time, I would have added the option to add tasks/a to-do list in addition to the schedule I currently have. This would allow the user to log events and tasks they need to complete. I would also make it so the user could remove specific events from each day instead of all events on that day.
